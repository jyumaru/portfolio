JYUMARU SNS Publisher / 運営：祠堂じゅまる

プライバシーポリシー

本ポリシーは、祠堂じゅまる（以下「運営者」）が運営するSNS連携アプリ「JYUMARU SNS Publisher」（以下「本アプリ」）における情報の取扱いを説明します。対象は本アプリのPinterest API連携です。

1. 本アプリの対象と用途

本アプリは、運営者自身が管理するPinterestビジネスアカウントへの投稿を支援するための個人利用アプリです。第三者向けのアカウント登録サービスは提供しません。オリジナルの画像・動画と説明文を指定したボードへ投稿し、投稿処理の状態を確認する目的でAPIを利用します。

2. 取り扱う情報

  • 認証したアカウントを確認するためのユーザーID、ユーザー名などの基本プロフィール情報。
  • 投稿先を確認するためのボード情報、および投稿結果を確認するためのピン情報。
  • 運営者が用意した画像・動画、タイトル、説明文、リンク、指定する公開時刻などの投稿用情報。
  • APIへの接続に必要なアクセストークン等の認証情報。
  • 重複投稿防止および障害調査に必要な処理状態や実行日時などの最小限の運用記録。

Pinterestのログインパスワードを本アプリで収集・保存することはありません。アカウントの認証はPinterestの公式な認証手段を使用します。

3. 利用目的

情報は、認証したアカウントの確認、指定した投稿の実行、投稿先と結果の確認、重複投稿や誤送信の防止、接続の管理、障害への対応に利用します。Pinterest由来の情報を、広告販売、第三者向けのデータ提供、AIモデルの学習に利用することはありません。

4. 保存と安全管理

認証情報は、運営者が管理するn8nの資格情報機能により暗号化して保存し、公開ページや投稿本文には掲載しません。投稿用の自作素材と必要な運用記録は運営者の管理環境で取り扱います。Pinterest由来の情報については公式の利用条件に従って取得・利用し、不要な情報の収集や第三者向けの情報の蓄積・提供は行いません。

5. 外部サービスへの送信

投稿の実行に必要な情報はPinterest APIへ送信されます。画像・動画・カバーの受け渡しに公開ストレージを利用する場合は、その素材をPinterestが取得します。投稿が公開された場合の公開範囲は、Pinterest上の投稿先とアカウントの設定に従います。本ポリシーのページはGitHub Pagesで配信します。

外部サービスによる情報の取扱いは、各サービスのポリシーもご確認ください。

  • Pinterest プライバシーポリシー
  • GitHub プライバシーに関する声明

6. 連携の停止・削除に関するお問い合わせ

連携はPinterestのアプリ連携設定から解除できます。運営環境内の認証情報や関連記録の削除に関するお問い合わせは、下記の窓口で受け付けます。連携を解除しても、Pinterest上にすでに公開されたピンが自動的に削除されるものではありません。公開済みの投稿はPinterest上で管理してください。
